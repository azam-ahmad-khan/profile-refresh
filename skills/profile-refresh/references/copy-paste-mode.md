# Copy-paste mode (no browser, or a chat-only AI)

You can't see or click LinkedIn, so the owner is your hands and eyes. Every LinkedIn step becomes a short instruction
they can follow on their phone or computer, plus a request to paste back what they see.

## Seeing the profile

Ask for these, one at a time, as plain text (select the text on the page, copy, paste) or screenshots:

1. The top of the profile: name, headline, location, and the company/school line.
2. The About section and each Experience entry (click "see more" first).
3. Licenses & certifications, Skills, Featured and Projects, if there are any.
4. For the privacy pass, the current value of each setting in [privacy.md](privacy.md). Give the exact menu path
   and ask "what does it say next to …?"

If a page looks different from the menu path you gave, ask what they see instead and adjust. Never guess.

## A draft and its save instructions, in one message

Show the draft block from SKILL.md, then add:

```
If yes: 1) go to <exact path>, 2) replace the text with the text below, 3) check "Notify network" is off,
4) Save, 5) reload the page and paste back what it shows now.
<the text, plain, ready to copy>
```

Before you mark it done, compare what they paste back with the approved text, word for word. Point out any
difference. A changed headline after a position edit is a known LinkedIn quirk ([linkedin-gotchas.md](linkedin-gotchas.md)).

## Pasting pitfalls

- Give text **without Markdown**. Asterisks, `#` and backticks show up literally on LinkedIn. Use "• " for bullets.
- Put About and description text in a plain code block so the line breaks survive copying. Ask them to check
  the paragraph breaks after saving.
- Count characters before you show a draft (headline 220, About 2,600, position description 2,000). If you can't count
  exactly, keep well under the limit and say so.

## Keeping state without files

- After each major step (privacy pass, positioning, each finished section), print the updated `career-notes.md` in
  full in a code block and ask the owner to save it as a file. If the chat ends early, nothing is lost.
- Print the new resume in full so they can paste it into their own document, saved under the dated name.
- At the end, remind them: "Next time, upload career-notes.md and your latest resume first."

## No web access

If you can't search the web, ask the owner to paste 2–3 job postings, and to check whether a product or partner is
on the employer's public website. Otherwise treat it as not public. Never present a made-up posting as real. If you
use typical requirements instead, label them clearly as "typical, not from a real posting".
