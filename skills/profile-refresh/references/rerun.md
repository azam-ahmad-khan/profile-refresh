# Re-run mode (periodic check-up)

The goal is small, incremental updates, not a rewrite. Keep everything the owner approved last time unless something
has changed.

## Checklist

- [ ] **1. Catch up.** Read `career-notes.md`: last run date, what is live, open questions, reminders, decisions, and
      *LinkedIn changes seen*. Tell the owner in 3–4 lines what happened last time and what's due now.
- [ ] **2. Due reminders first.** Any reminder whose date has passed or whose condition is now true, for example
      "turn public visibility back on when applying" or "remove Open to Work after accepting an offer". Then read the
      *Applications* table: flag follow-ups past their date, and for any *offer*, go through the "Accepted an offer"
      row below.
- [ ] **3. What's new?** Ask (one question at a time): new role, title or team? New project, certificate, publication
      or award? Are the target roles the same? Still job-hunting, and still employed? Read any new evidence they point
      to and add it to the ledger.
- [ ] **4. Drift check.** Open the live profile (in copy-paste mode, ask the owner to paste it) and compare it with *What is live* in the notes. Re-check the headline
      (adding a role can overwrite it), the Open to Work titles and visibility, and the privacy settings (repeat the
      [privacy pass](privacy.md) quickly: settings can reset).
- [ ] **5. Propose a short list** of updates, each with a reason and evidence. Typical ones: new role → experience
      plus headline; new project → Projects plus Featured; refreshed Open to Work titles; trimming old roles; resume
      re-sync.
- [ ] **6. Proof-of-work progress.** Ask how the suggested project is going. If it's done, add it
      ([proof-of-work.md](proof-of-work.md) §3). If it stalled, offer a smaller version. If the gap closed, suggest the next one.
- [ ] **7. Apply** each approved change: draft → confidentiality check → show → OK → save → reload → verify.
- [ ] **8. Update the notes** and set the next check-up date (about 3 months, or sooner if they are actively
      applying). If a scheduling tool is available, offer to set a reminder, and only set it if they say yes.

## Time-based triggers to watch

| Situation | Suggest |
|---|---|
| Started applying | Public visibility on; Featured up to date; Open to Work stays *Recruiters only* while employed unless the owner is fine with the employer knowing |
| Accepted an offer | Open to Work off; add the new role on the start date (notifications off); headline re-check |
| Left a job | End date on the role; decide what the headline says in between |
| 12+ months since the last role change | Refresh skills, About and resume dates |
