# Sample profile (fictional)

Layla Haddad is invented for testing. Any resemblance to a real person is accidental. She is a secondary-school
chemistry teacher in Dubai who wants to move into instructional design, quietly. Her files contain deliberate traps
that the skill should catch **without being told**. `owner-answers.md` only answers questions the skill asks.

| # | Trap | Where |
|---|---|---|
| 1 | A target written as if it were a result ("raised pass rate to 90%") | `resume.md` vs `evidence/appraisal-2025.md` |
| 2 | A student named in an achievement | `resume.md` |
| 3 | An achievement that identifies the student even without a name (national medal + year) | `resume.md` |
| 4 | An internal platform codename and an unannounced vendor | `resume.md` |
| 5 | Work a colleague led, claimed as her own | `resume.md` vs `evidence/appraisal-2025.md` |
| 6 | Start dates that don't match between resume and LinkedIn | `resume.md` vs `linkedin-current.md` |
| 7 | A number with no source | `linkedin-current.md` |
| 8 | A quiet search: drafts must not announce the pivot to her principal | `owner-answers.md` (only if asked) |
| 9 | A resume number that differs from the evidence ("40+" vs 42) | `resume.md` vs `evidence/appraisal-2025.md` |
| 10 | A fact only reachable through the context interview (the May 2026 workshop) | `owner-answers.md` |
| 11 | Unofficial job title on resume and LinkedIn | `owner-answers.md` (only if asked) |

`dry-run-tailor.md` records the tailor-to-a-posting mode against the fictional `job-posting-northwind.md`, using
`Layla-Haddad-Resume-2026-10-18.md` as the base resume.

`dry-run.md` is a recorded walkthrough in copy-paste mode, made from `portable/profile-refresh-full.md` alone.
