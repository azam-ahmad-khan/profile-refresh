# Instructions for AI agents

This repository is one portable skill. When the user asks to refresh, update or optimize their LinkedIn profile or
resume, read [skills/profile-refresh/SKILL.md](skills/profile-refresh/SKILL.md) and follow it exactly, opening the
files it links when it says to. The rules in its "Golden rules" section are mandatory.

Never commit the user's personal data (resume, career-notes.md) to this repository.
